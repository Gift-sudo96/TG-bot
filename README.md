# Бот-нагадувальник для продажів

Кидаєш боту скрін оплати або текст — бот нагадає про це у вказаний час.

## Запуск (5 кроків)

### 1. Встановити Python
```
winget install Python.Python.3.12
```
Після встановлення закрий і відкрий термінал заново.

### 2. Створити бота
Написати [@BotFather](https://t.me/BotFather) -> `/newbot` -> назва -> юзернейм.
У відповідь прийде токен виду `123456:AAA...`

### 3. Налаштувати
```
copy .env.example .env
```
Відкрити `.env` і вставити токен у `BOT_TOKEN`.
`ALLOWED_IDS` поки залишити як є — заповнимо на кроці 5.

### 4. Встановити залежності і запустити
```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

### 5. Додати себе і колегу в доступ
Напиши боту `/id` — він відповість твоїм ID. Хай колега теж напише `/id`.
Впиши обидва ID у `.env` через кому, перезапусти бота (Ctrl+C, потім `python bot.py`).

## Як користуватись

Кинь скрін або просто напиши текст, а десь у ньому згадай, коли нагадати.
Де саме згадаєш — не має значення:

```
завтра фіскалізувати
фіскалізувати оплату в 5к. завтра в 10.00
передзвонити Олені через 2 години
15 вересня продовжити підписку
в понеділок о 9 планерка
```

Решта тексту стане описом. Великі чи малі букви — байдуже.

Розуміє: `завтра` `післязавтра` `сьогодні` `в пн` `у п'ятницю`
`наступного вівторка` `15.09` `15.09.2027` `15 вересня` `о 14:30`
`в 10.00` `о 12 годині` `о 7 вечора` `вранці` `через 2 години`
`через тиждень` `+3д` `30хв`

**Якщо часу не вказати** — нагадає завтра о 9:00.

### Як це приходить

Скрін і підпис приходять одним повідомленням:

```
[ скріншот ]
⏰ фіскалізувати
на 09:00 · Сергій
[ ✅ Готово ]
```

**Поки не натиснули «Готово»**, нагадування повертається кожні 4 години,
але тільки з 9:00 до 21:00 — вночі бот мовчить і переносить на ранок.
З другого разу дописується `🔁 2-й раз`.

Натиснута кнопка міняє повідомлення **в обох чатах** одночасно:

```
✅ ~~фіскалізувати~~
закрито · Аріна · 09:14
```

Команди: `/list` — активні нагадування, `/cancel 12` — скасувати №12,
`/id` — свій Telegram ID.

### Налаштування (.env)

| Параметр | Що робить |
|---|---|
| `ALLOWED_IDS` | кому дозволено користуватись ботом |
| `NAMES` | як підписувати автора: `ID:Імʼя` через кому |
| `NOTIFY_ALL` | `true` — нагадування всім зі списку, `false` — лише автору |
| `DEFAULT_HOUR` | година, коли час не вказали |
| `REPEAT_HOURS` | крок повтору, за замовчуванням 4 години |
| `DAY_START` / `DAY_END` | межі, поза якими бот не турбує |

### Корисні скрипти

```
venv\Scripts\python.exe demo_flow.py "завтра фіскалізувати" --скрін
venv\Scripts\python.exe check_access.py
venv\Scripts\python.exe test_parse.py
venv\Scripts\python.exe test_repeat.py
```

## Важливо

- **Бот працює, лише поки запущений `python bot.py`.** Закриєш термінал —
  нагадування не приходять. Нічого не втрачається: при наступному запуску
  бот одразу дошле все прострочене. Для роботи 24/7 потрібен сервер.
- `.env` і `reminders.db` **не потрапляють у git** (див. `.gitignore`).
  Токен у публічному репозиторії = чужі люди керують твоїм ботом.
